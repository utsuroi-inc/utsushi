# 巻物 / makimono

Webページ全体を1枚の画像またはPDFとして保存するChrome拡張（Manifest V3）。

縦に長い1枚画像＝巻物、から。

**現在の状態：フェーズ3（エクスポート）まで実装済み。** 全ページを撮って、PNG / JPEG / PDF で保存、またはクリップボードへコピーできます。残りはフェーズ4（巨大ページの分割・オプション・ショートカット・多言語）とフェーズ5（堅牢化）。

## はじめ方

```bash
# 1. このディレクトリでGitリポジトリを初期化
git init
git add .
git commit -m "docs: 要件定義と開発計画"

# 2. Claude Codeを起動
claude
```

最初のプロンプト：

```
docs/requirements.md と docs/development-plan.md と CLAUDE.md を読んで、
フェーズ0を実装して。
完了したら、ビルド手順とChromeへの読み込み手順を教えて。
```

以降は `docs/development-plan.md` の §4 に各フェーズのキックオフプロンプトが用意してあります。**1セッション＝1フェーズ**で進め、フェーズが通ったら `/clear` してから次へ。

## 進め方の要点

- **フェーズ1（フルページ合成）が山場。** ここが通れば実用最小限のツールとして使えるので、一度実務投入して必要性を確かめてから先へ進んでよい
- **検証は人間がやるしかない。** ビルドが通っても、Chromeで実際に撮って繋ぎ目を目視するまで正しさは分からない
- **検証用サイトを固定する。** 毎フェーズ同じサイトで撮ることで、後のフェーズでの品質劣化に気づける（`docs/development-plan.md` §3）

---

## 設計の骨子

- **方式**：スクロール＆スティッチ（1ビューポートずつ撮って縦に連結）
- **権限**：`activeTab` / `scripting` / `storage` のみ。`<all_urls>` も `debugger` も使わない
- **通信**：ゼロ。ページ内容・URL・画像を一切外部送信しない。テレメトリなし
- **UI**：アイコンをクリックしたら即撮影。ポップアップは挟まない

`chrome.debugger` を使えば1回のAPI呼び出しで全ページを撮れますが、「デバッグ中」のインフォバーが出てユーザー体験を損なうため採用していません。

---

## 開発上の制約（重要）

同種の拡張機能が既に存在しますが、機能が同じツールを独自に実装すること自体は問題ありません（著作権法10条3項：解法＝アルゴリズムは保護対象外）。ただし以下は厳守します。

1. **他拡張のソースコードを参照しない**（依拠性を生じさせない）
2. **他社の登録商標にあたる語を名称・コード・ドキュメントに使わない**（対象の語と根拠は `docs/legal-notes.md` §2）
3. **アイコン・レイアウト・素材を既存製品に寄せない**

根拠と詳細は `docs/legal-notes.md`、実装上の遵守事項は `docs/requirements.md` §12 を参照。
