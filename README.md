# 写し / utsushi

**株式会社うつろいが開発・公開する、Webページ全体を画像またはPDFとして保存するChrome拡張です。**

ページを1画面ずつ撮影して縦につなぎ、長いWebページも記録できます。AIO/SEO監査、Web制作の現状記録、LPアーカイブ、マニュアル作成など、実務で「今のページをそのまま残したい」場面を想定しています。

- **外部送信なし**：拡張機能自身はページ内容・URL・スクリーンショットを外部サーバーへ送信しません
- **設定は端末内に保存**：設定値は `chrome.storage.local` を使い、Chrome Syncへ同期しません
- **権限は最小限**：`activeTab` / `scripting` / `storage` のみ。常時の全サイトアクセス権は要求しません
- **ワンクリック**：ツールバーのアイコンを押すと、その場で全ページ撮影を開始します
- **PNG / JPEG / PDF / コピー**：用途に合わせて書き出せます

## 使い方

詳しいインストール方法、撮影手順、設定、トラブルシューティングは [`USAGE.md`](USAGE.md) を参照してください。

最短では次の流れです。

1. `npm install`
2. `npm run build`
3. Chromeで `chrome://extensions` を開く
4. 「デベロッパーモード」をON
5. 「パッケージ化されていない拡張機能を読み込む」から `dist/` を選ぶ
6. 撮影したいWebページで「写し」アイコンをクリック

既定ショートカットは `Alt+Shift+P` です。

## 主な機能

- ページ全体のスクロール＆スティッチ撮影
- Retina / 高DPI対応
- fixed / sticky要素の重複写りを抑制
- lazy-load画像の読み込み補助
- 超巨大ページの自動分割
- PNG / JPEG / PDF保存
- クリップボードコピー
- ファイル名テンプレート
- 日本語 / 英語UI
- 撮影失敗・キャンセル時のページ状態復元

## プライバシーとセキュリティ

詳細は [`PRIVACY.md`](PRIVACY.md) を参照してください。

撮影時の一時データは拡張機能のIndexedDBに保存し、結果ページで読み出した後に削除します。設定は `chrome.storage.local` に保存します。アカウント機能、テレメトリ、外部APIへの送信処理はありません。

ページ側のDOMと衝突しにくいよう、撮影中に一時的に付与するID・属性名には撮影ごとのUUIDを含めています。復元処理は、その撮影が作成した要素・属性だけを対象にします。

## 既知の制限

- ページ内の独立したスクロール領域は、表示されている範囲のみ撮影されます
- 別ドメインiframeも可視範囲のみです
- 動画やCSSアニメーションは撮影時点のフレームが写ります
- 撮影中に別タブへ切り替えると安全のため中断します
- Shadow DOM内のfixed / sticky要素は自動非表示の対象外です
- 仮想スクロールや特殊なスクロール制御を行うページでは、繋ぎ目がずれる場合があります
- 画面200枚分を超える極端に長いページは撮影を中断します

うまく撮れない場合は、設定の「キャプチャ待機時間」を800〜1200ms程度へ増やしてください。

## 開発

Node.js 20以上を推奨します。

```bash
npm install
npm run typecheck
npm run build
```

開発中は以下を利用できます。

```bash
npm run watch
```

構成と設計判断は [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) を参照してください。
